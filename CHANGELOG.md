# Changelog

All notable changes to Weather CLI are documented here.

## [1.0.0] - First Public Release

- Added installation and usage documentation.
- Added application screenshots.
- Documented system architecture.
- Organized version history.
- Prepared the project for public distribution.

## [0.5.0] - CLI and Packaging

- Added command-line argument support.
- Added customizable forecast duration.
- Added Celsius and Fahrenheit support.
- Added help and version commands.
- Made the application installable as a CLI tool.

## [0.4.0] - Terminal Interface

- Integrated the Rich library.
- Added colorful weather panels.
- Added formatted forecast tables.
- Improved interactive prompts.
- Added loading indicators.

## [0.3.0] - Weekly Forecast

- Added seven-day weather forecasts.
- Added daily maximum and minimum temperatures.
- Added precipitation probability.

## [0.2.0] - City Selection and Reliability

- Added interactive location selection.
- Improved input validation.
- Added network error and timeout handling.
- Refactored the application into reusable functions.

## [0.1.0] - Initial Implementation

- Integrated the Open-Meteo Geocoding API.
- Integrated the Open-Meteo Weather API.
- Added current weather information.
- Implemented HTTP requests and JSON processing.

---

Versions 0.1.0 through 0.5.0 represent development
milestones tagged retrospectively.

Version 1.0.0 is the first public release.
